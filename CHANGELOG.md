# CHANGELOG

Todos los cambios importantes del proyecto PixelVault Store se documentan en este archivo.

## [1.0.0] - 2026-09-25

### Añadido
* Primera versión estable de PixelVault Store.
* Documentación técnica del proyecto móvil.
* Documentación de arquitectura del sistema.
* Diagramas UML de casos de uso.
* Diagrama UML de secuencia.
* Guía de instalación de la aplicación móvil.
* Documentación de API y servicios utilizados.
* Manual de usuario.
* Documentación de seguridad.
* Estructura de documentación organizada dentro de la carpeta `docs/`.
* Diagramas almacenados en `docs/assets/`.
* Persistencia de datos mediante AsyncStorage.
* Documentación de las principales funcionalidades de la aplicación.

### Funcionalidades documentadas
* Registro de usuarios.
* Inicio de sesión.
* Recuperación de contraseña.
* Catálogo de videojuegos.
* Categorías.
* Detalles de videojuegos.
* Carrito de compras.
* Cálculo del total.
* Pago simulado.
* Historial de compras.
* Perfil de usuario.
* Cierre de sesión.

### Notas
Esta versión corresponde a la primera versión estable documentada del proyecto.
El pago dentro de la aplicación es simulado y no representa una transacción bancaria real.
